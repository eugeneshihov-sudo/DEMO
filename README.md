## 📌 Обзор

Веб-приложение для визуализации, управления и симуляции компетенций сотрудников производственного предприятия. Теперь доступны два режима просмотра: **плоская тернарная диаграмма** (для анализа пропорций) и **интерактивная 3D-диаграмма** (для объёмного восприятия распределения). Встроена **симуляция «Жизнь процесса»**, где компетенции накапливают опыт, повышают уровень и стоимость. Добавлена **библиотека конфигураций** для сохранения и загрузки сценариев, а также **мануальный конструктор** – добавление компетенций через справочник.

Все данные хранятся в `localStorage`, изменения сохраняются между сессиями.

## 🚀 Основные возможности

### 📊 Двойная визуализация
- **Тернарная диаграмма** – классическое треугольное представление (нормализованные координаты).
- **3D-диаграмма (scatter3d)** – точки распределены по кубу, управление: вращение мышкой, зум колёсиком, наведение для подсказки.
- Обе диаграммы синхронизированы с фильтрами и поиском.

### 🧪 Симуляция «Жизнь процесса»
- На каждом шаге симуляции каждая компетенция получает **+1 час опыта**.
- При достижении порогов (50, 100, 250, 500 часов) автоматически повышается уровень (Junior → Middle → Middle+ → Senior).
- Стоимость часа пересчитывается с учётом нового уровня, категории и редкости.
- **Стрелочный индикатор** общей стоимости (в левой панели) показывает текущую сумму, дельту и цветовую зону (зелёный – стабильно, жёлтый – тревожно, красный – перегрев).
- **Три графика тренда** (средняя стоимость, средний уровень, количество) отображают динамику в реальном времени.

### ⚖️ Балансировка
- Кнопка **«Балансировка»** анализирует текущее распределение по категориям, сравнивает с целевыми долями (из ползунков) и добавляет недостающие компетенции в дефицитные категории (по 10% от недостатка), ускоряя процесс и предотвращая простои.

### 📚 Библиотека конфигураций
- Сохраняйте текущий набор компетенций вместе с долями категорий под любым именем.
- Загружайте ранее сохранённые конфигурации – они заменяют текущие данные и настройки.
- Удаляйте ненужные конфигурации.
- Все конфигурации хранятся в `localStorage` и доступны после перезагрузки страницы.

### 🛠 Мануальный конструктор (правый клик)
- **Правый клик по точке** на диаграмме → контекстное меню:
  - Редактировать (открывает карточку компетенции)
  - Удалить (с подтверждением)
- **Правый клик по пустому месту** → открывается модалка выбора из справочника (категория + название). После выбора открывается карточка редактирования с предзаполненными полями.
- В карточке добавления/редактирования появилась кнопка **«📂 Выбрать»** рядом с полем «Название» – она открывает тот же справочник, но с привязкой к текущей категории.

### ⚙️ Генерация компетенций
- **Левая панель** содержит все настройки: доли категорий (ползунки), количество компетенций, выбор бизнес-моделей.
- Кнопки **«Общага»** (равномерное распределение) и **«Выровнять до 100%»** (пропорциональная нормализация).
- При генерации новые компетенции получают осмысленные названия, зоны ответственности, расчётную стоимость и случайные координаты в кубе.

### 📋 Таблица компетенций
- Все поля: название, категория, часы, уровень, стоимость/час.
- Сортировка по любому столбцу.
- Фильтрация по категории и поиск по названию.
- Общая стоимость отображаемых записей (с учётом фильтров).

## 🛠 Технологии

- **Plotly.js** – 2D (scatterternary) и 3D (scatter3d) диаграммы, а также gauge-индикатор и графики тренда.
- **Чистый HTML, CSS, JavaScript** – интерфейс и логика.
- **localStorage** – хранение данных компетенций и библиотеки конфигураций.

## 📂 Структура данных

Каждая компетенция описывается объектом:

| Поле | Тип | Описание |
|------|-----|----------|
| `name` | string | Название компетенции |
| `category` | string | Одна из 13 категорий |
| `axis1` | number | Координата X (Технологии) – 0..1 |
| `axis2` | number | Координата Y (Люди) – 0..1 |
| `axis3` | number | Координата Z (Системы) – 0..1 |
| `hours` | number | Часы практики (накапливаются в симуляции) |
| `master_level` | string | Уровень: Junior, Middle, Middle+, Senior |
| `cost_hour` | number | Стоимость часа в рублях |
| `responsibilities` | array | Зоны ответственности (строки) |
| `contact` | string | Контактный email |
| `projects` | array | (опционально) Проекты |
| `presentation` | string | (опционально) Ссылка на презентацию |

**Библиотека конфигураций** хранит:
- `name` – название конфигурации
- `competencies` – массив объектов компетенций
- `weights` – объект с долями категорий (в процентах)
- `savedAt` – временная метка

## 🚀 Как использовать

### Запуск
1. Скачайте файл `index.html`.
2. Откройте его в современном браузере (рекомендуется Live Server или `python -m http.server`).
3. Все данные загружаются из `localStorage`; при первом запуске создаются демонстрационные записи.

### Управление диаграммами
- **Наведение** – подсказка с названием, категорией, часами и стоимостью.
- **Клик левой кнопкой** по точке – открывает карточку просмотра/редактирования.
- **Правый клик** – контекстное меню (см. выше).

### Симуляция
- Нажмите **«▶️ Симуляция»** в правом верхнем углу, чтобы открыть панель управления.
- Кнопки: **«Старт»**, **«Пауза»**, **«Сброс»**.
- Регулируйте скорость (100–1000 мс между шагами).
- **Стрелочный индикатор** в левой панели показывает общую стоимость и её изменение.
- **Графики тренда** обновляются в реальном времени.

### Библиотека конфигураций
- **«💾 Сохранить текущую»** – введите название, и текущий набор (компетенции + доли) будет сохранён.
- В списке библиотеки каждая запись имеет кнопки **📂** (загрузить) и **🗑️** (удалить).
- Загрузка заменяет текущие данные и доли, автоматически сбрасывая симуляцию.

### Мануальный конструктор
- **Правый клик по точке** – редактировать или удалить.
- **Правый клик по пустому месту** – выбрать из справочника, затем редактировать.
- В карточке добавления/редактирования кнопка **«📂 Выбрать»** рядом с полем «Название» позволяет выбрать компетенцию из справочника (с привязкой к выбранной категории).

### Генерация и настройка
- В левой панели настройте доли категорий (ползунки), количество компетенций и выберите бизнес-модели.
- Нажмите **«🚀 Сгенерировать»** – текущие данные будут заменены новым набором, фильтры и поиск сбросятся.

## 💡 Заметки для разработчиков

- **Хранилище**: все изменения сохраняются в `localStorage` под ключами `my_custom_competencies` (данные) и `competence_library` (библиотека).
- **Генерация**: использует словари `CATEGORY_NAMES_MAP` (названия по категориям) и `FALLBACK_RESPONSIBILITIES` (обязанности).
- **Расчёт стоимости**: функция `calculateCost` учитывает уровень, категорию, редкость (ключевые слова в названии) и округляет до 50 рублей.
- **Нормализация для тернарной диаграммы** выполняется на лету, в данных хранятся сырые координаты.
- **3D-диаграмма** отображает координаты без нормализации, что даёт равномерное заполнение куба.
- **Симуляция**: добавляет +1 час к каждой компетенции на каждом шаге, повышает уровень при достижении порогов, пересчитывает стоимость.
- **Индикатор** автоматически адаптирует шкалу под текущий максимум.
